# Compatibility

| Surface | Supported | Notes |
| --- | --- | --- |
| Codex / Agent Skills | Yes | Install with `npx skills add` or copy the Skill directory. |
| Inputs | Product links, images, drawings, public-record URLs, supplier notes | Use sanitized or public evidence for repository examples. |
| Jurisdictions | Public-record research is adaptable by jurisdiction | The user must specify country/region and cutoff date. |
| Output | Markdown, structured tables, checklists, and evidence bundles | Outputs are pre-screening artifacts, not legal opinions. |
| Network | Optional for fresh public-record research | Existing records can be analyzed offline. |
| Windows / Linux | Supported | Browser and public-record tooling are environment-dependent. |

If drawings, jurisdiction, or product scope are missing, return a bounded intake checklist and do not invent a collision conclusion.
