# Tutorial

## Tutorial 1: Product-link pre-screen

Use when a seller or product team supplies a marketplace URL, a few images, and a target market.

1. Paste the link, model/SKU, target jurisdiction, and launch deadline.
2. Add every available view and label whether it is a render, listing photo, or installed photo.
3. Ask for a design-patent pre-screen with a search cutoff and a confidence statement.
4. Review the candidate register, drawing-based scope notes, and separate risk rows.
5. If a candidate is serious, request three design-around directions and a second-pass search.

Example request:

```text
请对这个家居收纳产品做美国外观专利预筛。输入是产品链接、主图、侧视图和供应商给的型号。请输出搜索日志、候选专利、完整图纸保护范围、视图级对比、四类风险、三套可打样的规避方向，并标出仍需律师确认的事项。
```

## Tutorial 2: Supplier due diligence

Use when the product is sourced from a factory or trading company and rights ownership is unclear.

1. Supply the visible brand and seller plus all supplier, factory, designer, and legal-entity names.
2. Attach any complaint notice, indemnity clause, or supplier drawing.
3. Ask the skill to search portfolios and assignments around each serious candidate.
4. Compare the production drawing with the public product images and record mismatches.
5. Generate a supplier evidence request and a risk register separating ownership and platform exposure.

Example request:

```text
供应商声称产品原创，但卖家不是工厂。请沿品牌、贸易公司、实际工厂、设计师和权利人线索做外观设计权尽调，输出需要供应商补齐的证据清单，并把权属不确定性和平台投诉风险分开。
```

## Tutorial 3: Design-around to prototype

Use when a product concept is visually close to a serious candidate but the team must keep its job-to-be-done.

1. Declare must-keep function, installation points, material, load, tooling, cost, and packaging constraints.
2. Ask for a salience matrix and three structurally different directions.
3. Reject any direction that changes only color, logo, slot count, or one cross-section.
4. Select a preferred direction and request perspective, top, side/installed, and end views.
5. Turn the selected changes into supplier and prototype gates, then run a second-pass search.

Example request:

```text
我们要保留承重和安装孔位，但不能继续使用连续圆管、等距悬挂模块和中心桥。请生成三套外观结构差异明显、能交给供应商打样的设计规避方案，并列出成本下降时不得恢复的特征。
```

## Common mistakes

- treating a similar product title as proof of a relevant design right;
- comparing only the perspective image and ignoring top or end views;
- using a changed color or cross-section as a claimed safe harbor;
- publishing real supplier names, private complaint records, or unpublished applications;
- stopping after the first design-around without a second-pass search;
- presenting generated concept art as an engineering or legal clearance document.
